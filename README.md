🎬 Netflix Clone

A responsive Netflix-inspired streaming website built using HTML, CSS and JavaScript.
LIVE DEMO
https://netflix-clone-gilt-sigma-51.vercel.app/

This project was created to practice frontend development concepts such as responsive layouts, DOM manipulation, form validation, dropdowns, FAQ accordions, sliders and basic JavaScript interactions.

📌 Features
🎬 Netflix-inspired homepage
📱 Responsive design for desktop, tablet and mobile
🌐 English / Hindi language dropdown
🔐 Sign In page
✉️ Email validation
⚠️ Empty-field validation
▶️ Get Started functionality
🎞️ Trending movies/shows slider
⬅️➡️ Trending slider navigation arrows
❓ FAQ accordion
➕ FAQ plus/minus interaction
🎨 Netflix-style dark UI
🖼️ Movie/show poster cards
🔻 Footer language dropdown
📱 Responsive footer layout
🔗 Navigation between homepage and Sign In page
🛠️ Technologies Used
